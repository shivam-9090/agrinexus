# 3-minute demo script

1. **Hook (15s)** — "Small farmers can't access satellite data, soil analytics
   or climate forecasts — and there's no shared digital infrastructure for
   BRICS nations to cooperate on climate-resilient farming. AgriNexus is
   that shared infrastructure."

2. **Farm advisory (60s)** — Open the "Farm advisory" tab, search a real
   location (e.g. "Nagpur, India"), enter a soil test (N/P/K/pH/organic
   carbon). Submit. Point out: live 7-day weather (Open-Meteo), live
   satellite-derived agro-climatology (NASA POWER — solar radiation, root-zone
   soil moisture), the ranked AI crop recommendations with confidence and
   rationale, and the soil health score.

3. **Regenerative practices (30s)** — Scroll to the practice list; point out
   each recommendation is explainable (tied to a specific soil/climate
   signal), not a black box.

4. **Leaf diagnostics (30s)** — Switch tab, upload a leaf photo, show the
   stress-level result and recommended action. Be upfront: "v1 heuristic,
   documented upgrade path to a trained CNN once we have field images."

5. **BRICS cooperation (45s)** — Switch to "BRICS cooperation". Click
   "Simulate BRICS network sync" to register five demo regional nodes (India,
   Brazil, South Africa, Russia, China) and show the shared insights table.
   Emphasize: only aggregated, anonymized regional signals are exchanged —
   this is the digital-public-good / cross-border cooperation piece the
   brief explicitly asks for.

6. **Close (20s)** — Roadmap: real regional training data via the federation
   API, a trained CNN for disease detection, multi-language UI for BRICS
   farmers, SMS/WhatsApp delivery for low-connectivity areas.
